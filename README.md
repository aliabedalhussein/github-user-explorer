# GitHub User Explorer

A responsive web application that allows users to search GitHub profiles and explore public repositories using the GitHub REST API.

## Features

- Search GitHub users by username
- View profile information and statistics
- Browse public repositories with pagination
- Sort repositories by recently updated, name, or stars
- Filter repositories by programming language
- Handle API errors and network failures
- Responsive layout for desktop and mobile devices

**Note:** Star sorting and language filtering operate on the currently loaded repository page.

## Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- GitHub REST API

## How to Run

1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Launch `index.html` using Live Server.
4. Search for a GitHub username.

## API

This project uses the public GitHub REST API. No API key is required, but unauthenticated requests are subject to GitHub rate limits.
